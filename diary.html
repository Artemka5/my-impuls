Твои данные

Дневник хранится в твоём аккаунте. На другом устройстве войди в тот же аккаунт «Мой импульс». Фото доступны только владельцу записи.

В копию входят записи и идентификаторы фото. Сами фотографии в JSON не включаются.

Для мамы можно создать отдельный аккаунт по электронной почте. Дневники разных аккаунтов не смешиваются.

Распознавание фото использует Gemini. Если бесплатная квота закончится, ручной ввод продолжит работать.

Удобно на телефоне

Размер текста запоминается на этом устройстве.

Как установить

На iPhone открой сайт в Safari: «Поделиться» → «На экран “Домой”». На Android открой меню браузера → «Установить приложение» или «Добавить на главный экран». Если сайт открыт внутри другого приложения, сначала открой его во внешнем браузере.

Для загрузки и сохранения дневника нужен интернет. Установка не включает уведомления при закрытом приложении — для них используй календарь.

Восстановить записи

Выбери JSON-копию, скачанную из «Моего импульса». Сначала покажем, что будет добавлено. Существующие записи и настройки не перезаписываются.

До 5 МБ и 5000 записей. Фотографии восстановятся только если ещё доступны в этом аккаунте; остальные блюда будут добавлены без фото.

Удалить запись?

Запись будет удалена из твоего аккаунта.
