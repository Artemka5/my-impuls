# Мой импульс

Личный дневник веса, питания, активности и самочувствия.

Открыть: https://artemka5.github.io/my-impuls/

Вход — отдельный аккаунт по электронной почте с подтверждением адреса. Аккаунт ChatGPT не требуется.

Интерфейс размещён на GitHub Pages. Авторизация, записи и закрытые фотографии — в Supabase. Анализ еды выполняется серверной функцией через Gemini; оценку порции и калорий можно исправить вручную.

В этом репозитории находятся только публичные файлы интерфейса. Приватные ключи и записи пользователей здесь не хранятся. Публичный ключ Supabase предназначен для клиентского приложения; сервер проверяет пользователя и права доступа.

Старые записи можно перенести через JSON-копию из прежнего дневника. Фотографии в такую копию не входят.
