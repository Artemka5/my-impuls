# Мой импульс

Публичная стартовая страница личного фитнес-дневника.

Адрес GitHub Pages: https://artemka5.github.io/my-impuls/

Кнопка «Открыть дневник» ведёт в действующее приложение:
https://mama-fit-diary.sunnybean8.chatgpt.site/diary#today-section

Это стартовая страница, а не перенос серверного приложения. Авторизация, база данных, фотографии и Gemini работают на прежнем хостинге. Публикация страницы не меняет доступ к дневнику: нужен разрешённый аккаунт ChatGPT.

## Публикация

В Settings → Pages выберите Deploy from a branch → main → / (root).
Сборка и зависимости не нужны. В репозитории нет ключей API или личных записей.

## Изменения

`index.html` — содержимое, стили и анимации. `icon.svg` — значок сайта.
Анимации отключаются при системной настройке уменьшения движения.
